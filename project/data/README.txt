Place the Kaggle archive here as archive.zip.

Dataset: Google Play Store Apps
URL: https://www.kaggle.com/datasets/lava18/google-play-store-apps

Expected files inside the archive:
  - googleplaystore.csv
  - googleplaystore_user_reviews.csv

After running `python app/main.py`, two more files will appear here:
  - extracted/    (the unzipped CSVs)
  - playstore.db  (the populated SQLite database)
